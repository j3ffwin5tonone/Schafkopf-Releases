# Schafkopf Classic

Bayerischer Schafkopf für Windows: Spiele gegen drei Computerspieler, mit drei
KI-Stufen, Lernmodus, lokalem Spielstand und Statistik.

## Download

**[Aktuelle Version herunterladen](https://github.com/j3ffwin5tonone/Schafkopf-Releases/releases/latest)**

Wähle für Windows x64 entweder den **EXE-Installer** oder den **MSI-Installer**.
Du brauchst nur einen davon. WebView2 wird bei Bedarf während der Installation
heruntergeladen. Das Spiel selbst funktioniert offline.

Die Installer sind derzeit nicht mit einem Windows-Code-Signing-Zertifikat
signiert. Windows SmartScreen kann deshalb eine Warnung anzeigen.

## Prüfungen

Vor der Veröffentlichung werden automatisierte Tests, Prüfungen der
Abhängigkeiten und ein Microsoft-Defender-Scan ausgeführt. Zum Download gehören
`SHA256SUMS.txt` und `defender-scan.txt` mit den Prüfsummen und Scannerinformationen.
Ein manueller Windows-Installationstest steht für Version 0.1.0 noch aus.

## Lizenz

Kostenlos für private, nicht gewerbliche Nutzung. Es gelten die
[Lizenzbedingungen](LIZENZ.txt). Hinweise zu enthaltenen Bibliotheken stehen in
[LIZENZEN-DRITTER.txt](LIZENZEN-DRITTER.txt) und in der App.

Dieses Repository enthält ausschließlich Downloads, Nutzungshinweise und
Lizenztexte. Die automatisch von GitHub angebotenen „Source code“-Archive
enthalten diese Dokumente, nicht den Quellcode des Spiels.
